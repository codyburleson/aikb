# Capstone Guide

Guidelines for the capstone project for the [5-Day AI Agents Intensive Course with Google](https://www.kaggle.com/learn-guide/5-day-agents); copied here for quick reference.

Source: https://www.kaggle.com/competitions/agents-intensive-capstone-project

## Features to Include in Your Agent Submission

In your submission, you must demonstrate what you’ve learned in this course by applying at least three (3) of the key concepts listed below:

- Multi-agent system, including any combination of:
  - Agent powered by an LLM
  - Parallel agents
  - Sequential agents
  - Loop agents
  - ["Introduction to Agents" whitepaper](https://www.kaggle.com/whitepaper-introduction-to-agents)
  - [Day 1a - From Prompt to Action](https://www.kaggle.com/code/kaggle5daysofai/day-1a-from-prompt-to-action)
  - [Day 1b - Agent Architectures](https://www.kaggle.com/code/kaggle5daysofai/day-1b-agent-architectures)
- Tools, including:
  - MCP
  - Custom tools
  - Built-in tools, such as Google Search or Code Execution
  - OpenAPI tools
  - Long-running operations (pause/resume agents)
  - ["Agent Tools & Interoperability with Model Context Protocol (MCP)" whitepaper](https://www.kaggle.com/whitepaper-agent-tools-and-interoperability-with-mcp)
  - [Day 2a Lab - Agent Tools](https://www.kaggle.com/code/kaggle5daysofai/day-2a-agent-tools)
  - [Day 2b - Agent Tools Best Practices](https://www.kaggle.com/code/kaggle5daysofai/day-2b-agent-tools-best-practices)
- Sessions & Memory
  - Sessions & state management (e.g. InMemorySessionService)
  - Long term memory (e.g. Memory Bank)
  - ["Context Engineering: Sessions & Memory whitepaper"](https://www.kaggle.com/whitepaper-context-engineering-sessions-and-memory)
  - [Day 3a - Agent Sessions](https://www.kaggle.com/code/kaggle5daysofai/day-3a-agent-sessions)
  - [Day 3b - Agent Memory](https://www.kaggle.com/code/kaggle5daysofai/day-3b-agent-memory)
- Context engineering (e.g. context compaction)
- Observability: Logging, Tracing, Metrics
  - [Agent Quality whitepaper](https://www.kaggle.com/whitepaper-agent-quality)
  - [Day 4a - Agent Observability](https://www.kaggle.com/code/kaggle5daysofai/day-4a-agent-observability)
- Agent evaluation
  - [Day 4b - Agent Evaluation](https://www.kaggle.com/code/kaggle5daysofai/day-4b-agent-evaluation)
- A2A Protocol
  - [Day 5a - Agent2Agent Communication](https://www.kaggle.com/code/kaggle5daysofai/day-5a-agent2agent-communication)
- Agent deployment
  -  ["Prototype to Production" whitepaper.](https://www.kaggle.com/whitepaper-prototype-to-production)
  - [Day 5b - Agent Deployment](https://www.kaggle.com/code/kaggle5daysofai/day-5b-agent-deployment)
