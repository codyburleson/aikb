# Obsidian Guide

Guidelines from the AIKB team on how we like to configure and use Obsidian for our AIKB conformant knowledge vaults

## Obsidian Settings

- In Obsidian, go to Settings > Community plugins: Turn on community plugins
- Restricted mode: Turn on and reload
- Files and links >
  - Default location for new attachments: In subfolder under current folder (e.g., vault/folder/attachments)
  - Use `[[wiki links]]: off
- Appearance > Interface > Show inline title: off
- Daily Notes >
  - New file location: 3 Resources/Daily Notes
  - Template File Location: 3 Resources/Templates/DailyNote

## Obsidian Plugins

We recommend the following Obsidian plugins. The AIKB Reference Vault already has them installed and configured, but you can install them in any vault, and you can use this page as a reference to the recommended settings for Obsidian and each installed plugin.

- Community plugins: Browse
- Folder Notes, by [LostPaul](https://github.com/LostPaul)
  - General > Folder note name template: `{{folder_name}}: Index`
- Search the following plugins, install and enable each:
  - Tag Wrangler, by [PJ Eby](https://github.com/pjeby)
  - Templater, by [SilentVoid](https://github.com/SilentVoid13)
    - Template folder location: 3 Resources/Templates
