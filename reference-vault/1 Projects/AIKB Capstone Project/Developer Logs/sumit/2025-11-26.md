### Notes on Performance

A couple of things I noticed that might bite us later:

1.  **RAM Usage**: Right now, it loads the *entire text* of every file into memory. That's fine for now, but if the vault gets huge (1000+ files), it's going to eat all the RAM.
    *   *Idea*: We should probably switch to a metadata-only cache (Path, Modified Time, Tags) and only lazy-load the content when we actually need it.

2.  **Disk I/O**: It seems to re-scan the disk (`os.walk`) a lot—once at startup and again for every search.
    *   *Idea*: A persistent in-memory index would be better. We can just update it when files change instead of walking the disk every single time.
