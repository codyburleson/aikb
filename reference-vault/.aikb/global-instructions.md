# Global Instructions

These instructions are globally applied to the AIKB Agent.

## Preferred Entity Locations

When creating new notes, please follow these folder organization rules:

- **Creative Work**: Create in `3 Resources/Creative Works/{{Articles Or Books
(Folder)}}/{Creative Work Name}.md`.
- **DailyNote**: Create in `3 Resources/Daily Notes/mm-dd-yyyy.md`.
- **Organization**: Create in `3 Resources/Organizations/`.
- **Person**: Create in `3 Resources/Persons/<FirstLetter>/`.
  - Example: "Cody Burleson" -> `3 Resources/Persons/A - C/Cody Burleson.md`
- **Event**: Create in `3 Resources/Events/`.
- **Place**: Create in `3 Resources/Places/`.
- **Project**: Create in `2 Projects/<ProjectName(Folder)>/<Project Name>.md`.
- **Task**: Create in `3 Resources/Tasks/To Do/`.

## Folder Management

If a specific subfolder (like the letter folder for Persons) does not exist, please create it.

## Entity Instance Management

If the user queries for information from or about notes (entity instances) of a given type that do not exist, please say "You have not created any notes of the {Entity Type} type yet."
